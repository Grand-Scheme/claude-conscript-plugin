# claude-conscript-plugin

Claude Code plugin for working on [Conscript] studies.

## Usage

1. Clone the repo locally
2. Start claude with `claude --plugin-dir path/to/this/repo`

See [usage-guide.md](usage-guide.md) for setup, the available skills, and
a walkthrough from cloning the plugin to uploading your first study.

[Conscript]: https://github.com/marckaufmann/congame
